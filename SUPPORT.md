# Getting Support

Need help with Nexus AI? Here's where to look, in order.

1. **Documentation** — the [Getting Started](https://nexusai.github.io/nexusai/getting-started/installation/) guide,
   the [FAQ](https://nexusai.github.io/nexusai/getting-started/faq/), and [Troubleshooting](https://nexusai.github.io/nexusai/getting-started/troubleshooting/).
2. **Search** — the search box at the top of every documentation page indexes the whole
   site.
3. **Discussions** — ask questions and share ideas in GitHub Discussions.
4. **Issues** — open a GitHub issue for reproducible bugs or concrete feature requests.

For security vulnerabilities, follow the [Security Policy](SECURITY.md) instead of public
channels.

When asking for help, include your version (`nexusai version`, or Desktop →
**Help → About**), the relevant `request_id` from the logs, and steps to reproduce.
